Инструменты, оставленные на подоконнике.

Плагины и навыки, которыми школа агентов saharkit делится со всеми.

Подоконник — это место, куда выставляют вещи для того, кто мимо идёт: инструменты, которые делали для настоящей работы, а потом обобщали, пока они не стали полезны чужой машине. Всё здесь упаковано как плагин Claude Code, ставится парой команд и рассчитано на то, чтобы его не только запускали, но и читали.

Что стоит на подоконнике

  • agent-handbook

    Материалы, которые ты даёшь своему агенту, — общие суждения, без привязки к языку и стеку. Внутри инструмент, за которым тянешься, — /target-world-walk: он выводит, что нужно плану, проводя один настоящий кусок работы через ту систему, которую ты собираешься иметь. И правило, которое не вызывают вовсе, — правило флагеллантов: факт и починка вместо извинения, правила остановки вместо призывов. Настраивать нечего: ни рантайма, ни сети, ни железа.

  • voice-loop

    Диктовка и ответ вслух для Claude Code — держишь клавишу и говоришь, а ответы, которые стоит услышать, он читает вслух. Готовые голоса для английского, русского, украинского, немецкого, испанского и французского, сменные провайдеры речи — локально, на своём сервере или в облаке. Linux и macOS; на Windows — WSL2 + WSLg на Windows 11.

  • sill-core

    Общая основа, на которой стоят плагины, — не привязанное к плагину, версионированное по схеме, атомарно записываемое хранилище состояния ассистента с правилом «напомнить один раз». Один файл на плагин в XDG_STATE_HOME, отдельно от твоих настроек.

  • agent-statusline

    Одна строка внизу Claude Code: сколько израсходовано контекстного окна, сколько потрачено из недельного бюджета и какая модель отвечает. Все числа берутся из данных, которые оболочка сама передаёт скрипту на вход, поэтому строка не привязана к машине. Нужен только node — ни jq, ни сети, ни оборудования.

У каждого плагина — свои README, свои тесты, свои документы и своя версия. Со временем на подоконнике появится ещё.

С 2026-08-29 каждую статью здесь перед публикацией читает агент из другого репозитория, и спрашивают его не о том, ясно ли написано, а о том, может ли он начать. Там, где он отвечал, что не может, недостающее добавлялось. Статья про очередь мержа — первая, к которой это применено. Карта этой полки для агентов — llms.txt.

Добавь маркетплейс

В терминале:

claude plugin marketplace add saharkit/windowsill

Потом — уже внутри сессии Claude Code — поставь то, что хочешь:

/plugin install <plugin>@windowsill

voice-loop требует sill-core, поэтому ставь обе.
