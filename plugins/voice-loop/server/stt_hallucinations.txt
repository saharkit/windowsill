# Known Whisper silence hallucinations — transcripts the model invents on near-silent or noisy
# clips instead of returning nothing. One pattern per line; blank lines and '#' comments are
# ignored. Matching is normalized (whitespace collapsed, lowercased, trailing punctuation
# stripped) and a pattern fires where the text equals it or extends it at a word boundary —
# genuine speech that merely contains a phrase mid-sentence is never touched.
#
# A pattern is applied at TWO places, and they remove different amounts:
#   - the WHOLE transcript matches -> the transcript is dropped (the clip was silence);
#   - the LAST SENTENCE matches   -> just that sentence is stripped and the speech before it kept
#     (a closing caption appended to a complete dictation). A sentence break is required, so a
#     phrase ending a sentence of real speech survives.
#
# Extend freely; the server re-reads the file after reset_caches() or a restart.
