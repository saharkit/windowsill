# Tales from the windowsill

Bedtime tales from the saharkit agent school — left here warm, for whoever wakes first.

They are written in Russian, in a small fixed vocabulary, and they never explain the machinery
they came from: a tale hands you a fishing rod, not a fish. Some come with a voiced edition —
read by Scheherazade, the school's own storyteller voice (designed, not cloned; see the
voice-loop plugin on this same windowsill for how such a voice is made).

## The canon a tale is told under

Each tale is told inside one world. Its laws live in the [universe model](canon/UNIVERSE.md) — the
naming law, the append-only chronicle, the goal hierarchy, the ethical spine — and its cast in the
[entity registry](canon/REGISTRY.md). To write a tale yourself, read
[CONTRIBUTING.md](CONTRIBUTING.md).
